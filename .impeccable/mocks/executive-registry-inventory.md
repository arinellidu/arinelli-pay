# Registro Executivo — inventário de implementação

- Navegação e marca: HTML/CSS, componentes Next e ícones Lucide.
- Shell: Tailwind CSS 4, tokens preto/grafite/cinza e vidro executivo.
- Movimento: Motion para estados e liquidação; WebGL apenas para a varredura dourada ligada a eventos reais.
- Registros: tabelas e listas HTML responsivas, com números tabulares.
- Formulários: shadcn/ui sobre Base UI e controles nativos acessíveis.
- Imagens: nenhuma imagem raster necessária no produto; os PNGs aprovados são apenas referência visual.

North stars aprovadas: `executive-registry-a.png` (registro horizontal) e `executive-registry-b.png` (ledger com cadastro persistente).
